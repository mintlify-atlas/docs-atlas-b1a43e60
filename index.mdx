CineFinder is a movie management REST API that lets users browse films, write reviews, and organize movies into custom lists. It uses JWT-based authentication, supports paginated responses, and exposes an OpenAPI/Swagger UI for interactive exploration.

## Getting started

<Steps>
  <Step title="Clone and run the project">
    Clone the repository and start the application with Gradle. It runs on `http://localhost:8080` by default.
  </Step>
  <Step title="Register an account">
    Call `POST /auth/register` with your name, email, password, and age to create an account and receive a JWT token.
  </Step>
  <Step title="Authenticate requests">
    Include the token in the `Authorization` header as `Bearer <token>` on all protected endpoints.
  </Step>
  <Step title="Explore the API">
    Browse movies, create reviews, and build movie lists — or use the Swagger UI at `/swagger-ui.html` for interactive exploration.
  </Step>
</Steps>

<Note>
  The interactive Swagger UI is available at `http://localhost:8080/swagger-ui.html` when the application is running.
</Note>
