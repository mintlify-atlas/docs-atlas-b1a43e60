---
title: 'Quickstart'
description: 'Get the CineFinder API running locally and make your first request.'
---

<Note>
  The H2 in-memory database profile (`dev`) is the easiest way to run CineFinder locally — no external database required.
</Note>

<Steps>

  <Step title="Prerequisites">
    Make sure you have the following installed before continuing:

    - **Java 17 or later** — verify with `java -version`
    - **Gradle** — the project includes the Gradle wrapper (`./gradlew`), so a system-level install is optional
    - **A database** — use H2 for local development (bundled) or Oracle/PostgreSQL for production
  </Step>

  <Step title="Clone the repository">

    ```bash
    git clone https://github.com/challengezinho/cinefinder-java-advanced.git
    cd cinefinder-java-advanced
    ```

  </Step>

  <Step title="Run with H2 (recommended for development)">
    The `dev` Spring profile switches the datasource to an H2 in-memory database and applies the H2-compatible Flyway migrations automatically. No configuration is needed.

    ```bash
    ./gradlew bootRun --args='--spring.profiles.active=dev'
    ```

    The application starts on port `8080`.
  </Step>

  <Step title="Run with Oracle (production)">
    To connect to an Oracle database, update `src/main/resources/application.yaml` with your connection details:

    ```yaml
    spring:
      datasource:
        url: jdbc:oracle:thin:@<host>:<port>:<sid>
        username: <your-username>
        password: <your-password>
        driver-class-name: oracle.jdbc.OracleDriver
      jpa:
        database-platform: org.hibernate.dialect.OracleDialect
      flyway:
        locations: classpath:db/migration/oracle
    ```

    Then start the application without a profile override:

    ```bash
    ./gradlew bootRun
    ```
  </Step>

  <Step title="Verify the application is running">
    Once the application starts, open Swagger UI in your browser to confirm it is healthy:

    ```
    http://localhost:8080/swagger-ui.html
    ```

    You can also check the OpenAPI spec directly:

    ```bash
    curl http://localhost:8080/v3/api-docs
    ```
  </Step>

  <Step title="Register a user and receive a JWT token">
    Register a new user account by sending a `POST` request to `/auth/register`. The response body is a JWT token string.

    <CodeGroup>

    ```bash cURL
    curl -X POST http://localhost:8080/auth/register \
      -H "Content-Type: application/json" \
      -d '{
        "name": "Jon",
        "email": "jon@email.com",
        "password": "123456",
        "age": 20
      }'
    ```

    </CodeGroup>

    **Response:**

    ```
    eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJqb25AZW1haWwuY29tIiwiaWF0IjoxNzA...
    ```

    Save this token — you will need it for all subsequent requests.
  </Step>

  <Step title="Make your first authenticated request">
    Use the token from the previous step in the `Authorization` header to fetch the movie catalog:

    <CodeGroup>

    ```bash cURL
    curl http://localhost:8080/api/movies \
      -H "Authorization: Bearer eyJhbGciOiJIUzI1NiJ9..."
    ```

    </CodeGroup>

    A successful response returns a paginated list of movies:

    ```json
    {
      "content": [
        {
          "id": 1,
          "title": "Inception",
          "description": "Filme sobre sonhos",
          "releaseDate": "2010-07-16",
          "averageRating": 9.60,
          "genres": ["SCI_FI", "ACTION"],
          "posterUrl": null
        }
      ],
      "totalElements": 4,
      "totalPages": 1,
      "number": 0,
      "size": 20,
      "first": true,
      "last": true,
      "empty": false
    }
    ```
  </Step>

</Steps>
